# OlistPlayground2

OlistPlayground2 is an app for organizing personal lists and tracking media interests, built with React Native and [Expo](https://expo.dev). Keep a reading list, plan movies to watch, or track your progress through anime and manga alongside other collections.

## What you can do

- **Organize lists:** Create lists, reorder and pin them, and browse them in row or grid views. Configure lists with optional fields such as tags, notes, ratings, and progress.
- **Track media:** Add items to lists and update their status, such as planned, active, or completed. Record progress in episodes, chapters, volumes, items, or percentages.
- **Discover titles:** Search catalogs for books, movies and TV shows, anime, and manga, view details, and add results to your lists.

The app is under active development. Home is a placeholder prototype, and Community is a prototype using mock feeds alongside locally created posts. Explore also includes placeholder discovery sections; its Games and People search scopes do not currently query a catalog.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).
